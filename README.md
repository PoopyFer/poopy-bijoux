# Poopy Bijoux - Sitio Web de Joyería Artesanal

> *Diseños únicos que conectan con tu estilo y esencia.*

Este es el proyecto final del curso de **Desarrollo Web**, una página web completa para **Poopy Bijoux**, una marca de accesorios hechos a mano con identidad **boho chic** y **minimalista**.

## 🌿 Sobre la Marca
Poopy Bijoux crea **joyas artesanales únicas** pensadas para mujeres de 18 a 30 años que aman el estilo auténtico, elegante y con alma boho.  
Los diseños están inspirados en el mar, la naturaleza y los detalles artesanales.

### Líneas de producto:
- Collares, aros y pulseras
- Piedras naturales y cristales
- Cadenas doradas, plateadas y cobrizas
- Hilo trenzado y detalles playeros

📍 Hecho a mano en **Recoleta, Buenos Aires, Argentina**

## 🛠️ Tecnologías Usadas
- HTML5 (estructura semántica)
- CSS3 (con metodología BEM)
- Bootstrap 5 (diseño responsive)
- Font Awesome (iconos)
- Optimización SEO completa (meta tags, Open Graph, alt text, title)
